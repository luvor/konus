# Contributing

Thanks for taking a look at Konus!

- Follow the [README build instructions](README.md#build) for your platform.
- Run the frame check described in [Local checks](README.md#local-checks) when your change touches video frames.
- Keep diffs small and follow the existing QML style.
- Send one focused change per pull request.
- Include before/after screenshots for UI changes.
- Keep the implementation faithful to [Juxtopposed’s Figma design](https://www.figma.com/community/file/1691465999134370980), while noting where an adaptation is needed for a working player.
